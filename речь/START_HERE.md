# Как запустить «Речь»

У тебя две части: сайт на GitHub Pages и маленький защищенный посредник для ИИ на Cloudflare. История остается на iPhone. Для настройки понадобится компьютер; после настройки он не нужен.

## Что нужно подготовить

Для запуска нужны аккаунты GitHub, Cloudflare и OpenAI API. Настройка выполняется один раз с компьютера; затем приложение работает с iPhone, компьютер можно выключить.

Разбор уже настроен на **GPT-6 Luna**, API-название `gpt-6-luna`. Она разбирает текст. Для перевода аудио в текст оставлена `gpt-4o-mini-transcribe`, потому что Luna не поддерживает входящее аудио. Обе используют один и тот же ключ OpenAI.

| Что | Откуда взять | Куда добавить |
| --- | --- | --- |
| `OPENAI_API_KEY` | Создать в своем аккаунте OpenAI API | Только в секреты Cloudflare Worker |
| `ACCESS_TOKEN` | Сгенерировать случайную строку командой ниже | В секреты Cloudflare и в поле «Личный код доступа» на iPhone |
| `gpt-6-luna` | Уже указано в проекте | Это публичное название модели, не секрет |

**В GitHub не загружай значения обоих секретов.** В `wrangler.toml` должны быть только домен сайта и названия моделей. `.gitignore` помогает при работе через Git, но не защищает файл, который вручную перетащили в веб-загрузчик GitHub.

Сайт можно опубликовать до настройки ключа или после. Ключ остается в Cloudflare; его добавление не требует пересобирать или заново загружать сайт.

Если секрет случайно попал в репозиторий, сначала отзови его или замени. Удаление строки из последней версии не убирает ее из истории Git.

## 1. Опубликовать сайт

1. Распакуй архив `Rech_iPhone_PWA.zip`.
2. В GitHub создай новый **публичный** репозиторий, например `rech`. В бесплатном GitHub Pages код сайта будет публичным. Настоящих ключей в файлах нет.
3. Загрузи содержимое папки `rech` в корень репозитория: на верхнем уровне должны быть `docs`, `worker`, `scripts`, `tests`, `README.md`, `package.json`. Не загружай сам ZIP.
4. Открой **Settings → Pages → Build and deployment**.
5. Выбери **Source: Deploy from a branch**, ветку **main**, папку **/docs**, затем **Save**.
6. Дождись появления опубликованного адреса, например `https://ТВОЙ-НИК.github.io/rech/`.

Если загружать через веб-интерфейс неудобно, открой папку в GitHub Desktop и опубликуй ее как репозиторий. Не загружай `.dev.vars`, `.env` или файлы с настоящими ключами.

В архиве также есть необязательный `.github/workflows/pages.yml` для публикации через GitHub Actions. **Выбери один способ:** если используешь этот workflow, в пункте Source выбери **GitHub Actions**. Вариант через ветку `/docs` работает без пользовательского workflow; при выборе этого варианта не добавляй `pages.yml` в репозиторий.

## 2. Создать ключ для ИИ

В аккаунте [OpenAI API](https://platform.openai.com/) создай API-ключ для своего проекта и настрой оплату/контроль расходов. Подписку ChatGPT не следует считать настроенным балансом API. Ключ понадобится только при настройке Cloudflare, в приложении на iPhone он не используется.

Не присылай ключ в чат и не вставляй его в GitHub.

## 3. Настроить посредник

Создай аккаунт Cloudflare и установи [Node.js LTS](https://nodejs.org/) версии 22 или новее на компьютер. Открой Терминал в распакованной папке `rech`.

В файле `worker/wrangler.toml` замени:

```toml
ALLOWED_ORIGIN = "https://YOUR_GITHUB_USERNAME.github.io"
```

на домен своего GitHub Pages, например:

```toml
ALLOWED_ORIGIN = "https://irina.github.io"
```

Без `/rech/` и без слеша в конце. Для собственного домена впиши его HTTPS-origin. Проверь, что рядом уже указано `ANALYSIS_MODEL = "gpt-6-luna"`. Остальные настройки для начала оставь как есть.

Выполни по очереди:

```bash
npx wrangler@4 login
npm run worker:deploy
```

Первая команда откроет вход в Cloudflare. Вторая создаст Worker и покажет его адрес вида `https://rech-api.ТВОЙ-АККАУНТ.workers.dev`. До добавления секретов он закрыт и не выполняет платные запросы.

Добавь ключ OpenAI:

```bash
npx wrangler@4 secret put OPENAI_API_KEY --config worker/wrangler.toml
```

Когда Терминал попросит значение, вставь API-ключ. Он сохранится в секретах Cloudflare, не в исходном коде.

Теперь создай **отдельный личный код доступа** к своему посреднику:

```bash
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

Сохрани получившуюся строку в менеджере паролей. Затем выполни:

```bash
npx wrangler@4 secret put ACCESS_TOKEN --config worker/wrangler.toml
```

Вставь сгенерированный личный код. Именно его ты введешь на iPhone. Не используй здесь ключ OpenAI. Минимальная длина кода — 32 символа.

Посредник не требует базы данных. Тариф и доступность Cloudflare проверь в своем аккаунте; расходы OpenAI оплачиваются отдельно. Для работы ограничителя требуется Wrangler 4.36.0 или новее; `wrangler@4` получает актуальную четвертую версию.

## 4. Добавить на iPhone

1. Открой опубликованный сайт в Safari.
2. «Поделиться» → «На экран Домой».
3. Включи «Открыть как веб-приложение», нажми «Добавить».
4. Открой **именно новую иконку «Речь»**.
5. Нажми шестеренку.
6. Введи HTTPS-адрес Worker и личный код `ACCESS_TOKEN`.
7. Разреши обработку речи ИИ, нажми «Сохранить подключение».
8. Нажми «Проверить подключение». Проверка подтверждает доступность посредника и наличие настроек. Она не делает платный запрос и не проверяет баланс OpenAI.

## 5. Первая тренировка

1. Выбери «Одна мысль».
2. Нажми микрофон и разреши запись в Safari.
3. Говори 30–60 секунд, затем нажми «Завершить».
4. При желании прослушай запись. Нажми «Расшифровать ответ».
5. Проверь текст и исправь ошибки распознавания.
6. Нажми «Получить разбор». Результат сохранится в истории автоматически.
7. Нажми «Попробовать еще раз», чтобы повторить ту же тему и сравнить два ответа.

Для проверки без микрофона есть кнопка «Вставить готовый текст». В этом режиме время и темп не выдумываются.

## Если что-то не работает

| Сообщение/ситуация | Что проверить |
| --- | --- |
| «Этот адрес сайта не разрешен» / ошибка подключения | `ALLOWED_ORIGIN` должен точно совпадать с доменом сайта; после изменения выполни `npm run worker:deploy`. Не добавляй путь репозитория. |
| «Неверный личный код» | На iPhone вводится `ACCESS_TOKEN`, а не ключ OpenAI. |
| «Сервер еще не настроен» | Оба секрета добавлены; ограничитель `RATE_LIMITER` оставлен в конфигурации. |
| «Лимит API или баланс исчерпан» | Проверь оплату, доступ к модели и лимиты OpenAI; если было много запросов подряд, подожди минуту. |
| «Проверь ключ OpenAI» | Добавь действующий ключ заново командой `secret put OPENAI_API_KEY`. |
| Нет микрофона | Открой HTTPS-сайт в Safari, разреши микрофон в настройках сайта. |
| Запись прервалась | Во время записи держи приложение открытым. Звонок, блокировка или сворачивание могут остановить аудио в iOS. |
| История в Safari и в иконке разная | Используй установленную PWA постоянно; перенеси историю через резервную копию, если нужно. |
| Новый дизайн не появился | Закрой приложение и вкладки сайта, затем открой с интернетом. При обновлении кода нужно менять версию кеша в `docs/sw.js`. |

## Как удалить или сохранить историю

- В «Истории» нажми корзину у записи или проведи по ней влево.
- Для нескольких записей: «Выбрать» → отметь нужные → «Удалить выбранные».
- Для полного удаления: настройки → «Очистить всю историю» → подтверждение.
- Перед очисткой или обновлением: настройки → «Сохранить резервную копию» → сохранить JSON в «Файлы». Восстановление — «Восстановить из файла».

Удаление результата не удаляет упражнение из каталога. Аудио в истории отсутствует. Удаление локального результата не является запросом на удаление технических данных, которые поставщик API может хранить согласно своей политике.

## Обновление уже запущенного проекта на Luna

Замени код `worker/` файлами из этого архива и выполни `npm run worker:deploy`. В `worker/wrangler.toml` сохрани свой `ALLOWED_ORIGIN`, а `ANALYSIS_MODEL` оставь равным `gpt-6-luna`. Секреты остаются в Cloudflare при обычном повторном развертывании того же Worker. История на iPhone не меняется. Если Worker еще не был создан, следуй основной инструкции выше.

Модель сверена 30 сентября 2026 с официальной документацией: https://developers.openai.com/api/docs/models/gpt-6-luna
