# Речь

Личный тренажер ясной речи для iPhone. Интерфейс в стиле iOS, шесть упражнений, запись ответа, редактируемая расшифровка и разбор через OpenAI API. История находится только в браузерном хранилище устройства.

**Начни с [START_HERE.md](START_HERE.md).** Проект собран, но не опубликован и не подключен к платному API. В архиве нет настоящих секретов.

## Возможности

- Одна мысль за минуту; пересказ; свободный ответ; сокращение текста; прогон урока; история по шагам.
- Несколько готовых тем для каждого упражнения, своя тема, исходные тексты для пересказа и сокращения.
- Три режима опоры: подсказки, план, без опоры. Пункты плана переключаются вручную.
- Запись, пауза, продолжение, прослушивание; автоостановка через 5 минут. При уходе в фон приложение пытается поставить запись на паузу. iOS может приостановить страницу раньше события, поэтому записывай на открытом экране.
- Отдельные запросы на расшифровку и разбор: можно проверить и исправить текст перед анализом.
- Ввод готового текста без микрофона; черновики сохраняются локально; ошибка ИИ не удаляет текст.
- Разбор по задаче: конкретные сильные стороны, максимум два улучшения, пример формулировки, один фокус на следующую попытку. Никаких фиктивных оценок уверенности или голоса по тексту.
- Повторная попытка с той же темой, сравнение двух текстов.
- История с поиском и фильтром, удаление одной тренировки (кнопкой или свайпом), нескольких выбранных, всей истории с подтверждением. Отмена удаления доступна 9 секунд. Массовая очистка не имеет отмены.
- Статистика выводится из сохраненных результатов, удаленные результаты исключаются.
- Резервная копия JSON: экспорт, импорт с валидацией, объединение без перезаписи существующих ID. Аудио и код доступа в копию не входят.
- PWA: иконка на экране iPhone, кеш интерфейса и упражнений; история читается офлайн. Обработка ИИ требует интернета.

## Архитектура

`docs/` — статические HTML/CSS/JS для GitHub Pages. Сборка и npm-зависимости для интерфейса не нужны. `IndexedDB` содержит тексты, результаты и метаданные. В `localStorage` находятся адрес Worker, личный код доступа и согласие на обработку.

`worker/` — Cloudflare Worker, который проверяет origin и личный код, ограничивает размер и частоту запросов и передает данные в OpenAI. У него нет базы данных или файлового архива. Ограничитель хранит только счетчики запросов, не историю упражнений.

Модели по умолчанию:

- расшифровка: `gpt-4o-mini-transcribe`, русский язык, JSON;
- разбор: `gpt-4o-mini`, Responses API со строгой JSON-схемой и `store:false`.

Модели меняются серверными переменными в `worker/wrangler.toml`, не браузерным запросом. Анализатор получает текст, условия упражнения и исходный материал, но не аудио. Поэтому он не оценивает произношение, интонацию, мычание, реальную длительность пауз или точное количество слов-паразитов. Приблизительный темп вычисляется локально из числа распознанных слов и времени записи, с исключением нажатой паузы.

## Запуск на компьютере

Нужен Node.js 22 или новее:

```bash
npm start
```

Открой `http://localhost:8080`. Это сервер только для интерфейса, он не обрабатывает ИИ-запросы. Не открывай `index.html` двойным щелчком: ES-модулям и Service Worker нужен HTTP/HTTPS.

Для локальной разработки посредника:

1. Скопируй `worker/.dev.vars.example` в `worker/.dev.vars` и впиши секреты локально.
2. Добавь `http://localhost:8080` к `ALLOWED_ORIGIN` через запятую.
3. Выполни `npm run worker:dev` и укажи его адрес (обычно `http://localhost:8787`) в настройках приложения.
4. Перед публикацией убери localhost из разрешенных адресов.

## Проверки

```bash
npm test
```

Встроенные Node-тесты проверяют границы доверия посредника, ограничения размеров, авторизацию, CORS, ошибки API, схему разбора, безопасное отображение и импорт копий. Они используют заглушку OpenAI и не тратят деньги.

В `tests/browser.mjs` находятся проверки пользовательских сценариев. Для запуска отдельно установи Playwright, загрузи браузеры и запусти локальный сайт:

```bash
npm install --no-save playwright
npx playwright install chromium webkit
npm start
# В другом окне:
node tests/browser.mjs
```

Результат проверки поставляемой версии см. в `TEST_REPORT.md`. Проверка на настольном WebKit не заменяет тест на физическом iPhone. Секреты и доступ к OpenAI в этой сборке не были предоставлены, поэтому реальные платные запросы не выполнялись.

## Ограничения и сохранность данных

- Аудио существует в оперативной памяти страницы, пока ты прослушиваешь или повторяешь неудачный запрос. После успешного сохранения расшифровки оно освобождается. При перезагрузке, выходе из упражнения или закрытии приложения аудио теряется. В IndexedDB, Service Worker cache и резервные копии оно не записывается.
- Локальная история не является облачной резервной копией. Очистка данных сайта, удаление PWA, нехватка места или действия iOS могут ее удалить. Регулярно сохраняй JSON в «Файлы». При выборе iCloud Drive копию уже хранит твой iCloud, по твоему выбору.
- Safari и установленная PWA могут использовать отдельные хранилища. Сначала добавь приложение на экран, затем настрой подключение и тренируйся в нем. Для переноса между контекстами используй экспорт и импорт.
- `store:false` отключает сохранение состояния Responses, но не является обещанием нулевого хранения у поставщика. Условия журналирования и хранения OpenAI зависят от аккаунта и действующих правил. Передаются аудио для расшифровки и текст/тема/исходный материал для разбора.
- Worker не пишет тело запросов в логи, observability отключена. Технические метаданные платформы могут обрабатываться Cloudflare.
- Личный код доступа — пароль к твоему посреднику. Он локально хранится на телефоне. Не публикуй его и не делись им. Ключ OpenAI никогда не вводится в интерфейс и не включается в экспорт.
- Лимит Worker: 10 платных запросов за 60 секунд в одной локации Cloudflare; это ограничение частоты, не жесткий глобальный денежный бюджет. Один полный разбор обычно состоит из двух запросов. Лимиты и уведомления расходов настраиваются отдельно в аккаунте API.
- После отмены ожидания запрос, уже полученный поставщиком, может завершиться и быть тарифицирован. Автоматических платных повторов нет.
- Сайт не защищен от просмотра по публичному адресу: это нормально для GitHub Pages. В нем нет твоей истории и API-ключа. Рабочие запросы защищены личным кодом и origin-проверкой.

## Обновление

Перед обновлением сохрани резервную копию. Меняй файлы в `docs/`, увеличивай версию `CACHE` в `docs/sw.js`, публикуй. Новый Service Worker активируется после закрытия старых окон приложения; на следующем открытии будет использоваться новый кеш. Хранилище истории от обновления файлов не очищается.
